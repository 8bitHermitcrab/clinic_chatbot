# 성형외과 상담 챗봇 (Clinic Chatbot)

눈·코 성형외과의 환자 문의에 답하는 한국어 챗봇입니다.
예전 회사에서 사내 테스트까지만 진행했던 **의도 분류 + 정해진 답변** 방식의 챗봇을, **의도 분류 라우터 + RAG + 안전 가드레일** 구조로 다시 설계하고 있습니다.

## 이전 버전과 달라진 점

| | 이전 버전 | 이번 버전 |
|---|---|---|
| 방식 | 의도 분류 → 정해진 답변 | 의도 분류 → 의도별로 다른 처리 경로 |
| 답할 수 있는 범위 | 미리 정한 의도만 (오시는 길, 진료시간 등) | 정형 정보 + 시술 관련 자유 질문 |
| 시술 상세 문의 | 상담사 연결만 가능 | 문서 근거로 일반 정보 답변, 개인 상담은 연결 |
| 위험한 질문 | 별도 처리 없음 | 부작용 의심 질문은 답변 없이 즉시 병원 연결 |

## 구조

```
사용자 질문
  → 의도 분류 (9개 의도)
  → 시술명 추출 (쌍수, 지재 같은 줄임말 정규화)
  → 의도별 처리
       ├ 위치 · 전화번호 · 진료시간 · 시술 목록 → 병원 데이터로 템플릿 답변
       ├ 수술 후 관리 · 시술 정보             → RAG (문서 검색 + LLM 답변)
       ├ 상담 · 예약                          → 상담 연결
       ├ 부작용 의심                          → 답변 없이 즉시 병원 연락 안내
       └ 범위 밖                              → 정중히 거절
```

## 의도 목록

| 의도 | 설명 | 예시 |
|---|---|---|
| `location` | 위치, 교통, 주차, 병원 이름 | 강남역 몇 번 출구예요? |
| `phone` | 전화번호, 카톡 채널 등 연락처 | 병원 번호 알려주세요 |
| `hours` | 진료시간, 휴진일 | 토요일에도 해요? |
| `procedure_list` | 이 병원에서 하는 수술인지 | 하안검도 해요? |
| `aftercare` | 수술 후 관리, 정상 회복 과정 | 매몰 3일짼데 냉찜질 계속 해요? |
| `procedure_info` | 수술 방법, 차이, 가격, 마취 | 매몰이랑 절개 차이가 뭐예요? |
| `consult_booking` | 예약, 상담 연결, 결과 불만, 개인 진단 요청 | 라인이 맘에 안 들어요 상담 받고 싶어요 |
| `side_effect` | 부작용 의심 증상 (출혈, 고름, 열, 시야 이상 등) | 수술 부위에서 피가 계속 나요 |
| `out_of_scope` | 병원과 무관한 질문, 인사, 잡담 | 강남역 맛집 추천해줘 |

## 폴더 구성

```
clinic_chatbot/
├── data/
│   ├── hospital.json         # 가상 병원 정보 (위치, 연락처, 진료시간)
│   ├── procedures.json       # 눈·코 시술 11종 (설명, 동의어, 수술 후 관리, 위험 신호)
│   ├── intent_dataset.csv    # 의도 분류 데이터 2,295문장
│   └── train / val / test.csv  # split_data.py 로 생성 (8:1:1)
├── notebooks/
│   └── 01_intent_classifier.ipynb   # 베이스라인 + KLUE-RoBERTa 학습·비교
├── app/
│   ├── classifier.py         # 학습된 모델로 의도 분류 (의도별 확률)
│   ├── extractor.py          # 시술명 추출 (동의어 사전, 애매한 표현·안 하는 수술 구분)
│   ├── router.py             # 처리 방식 결정 (위험 → 병원 연결, 애매 → 되묻기, 그 외 → 답변)
│   └── cli.py                # 터미널에서 질문 넣어보기
├── tests/                    # 모델 없이 돌아가는 추출기·라우터 테스트
├── outputs/                  # 학습된 모델 (가중치 파일은 용량 때문에 깃허브에 없음)
├── results/                  # 실험 결과
├── split_data.py             # 데이터 분할 스크립트
└── requirements.txt
```

## 실행 방법

### 코랩 (추천)

1. `notebooks/01_intent_classifier.ipynb` 를 코랩에서 엽니다.
   GitHub에서 노트북 파일을 열고 주소의 `github.com` 을 `githubtocolab.com` 으로 바꾸면 바로 열립니다.
2. **런타임 → 런타임 유형 변경 → T4 GPU** 선택
3. 위에서부터 차례로 실행 (첫 셀이 저장소를 받고 데이터를 나눕니다)

### 내 컴퓨터

```bash
git clone https://github.com/8bitHermitcrab/clinic_chatbot.git
cd clinic_chatbot
pip install -r requirements.txt
python split_data.py
```

`outputs/` 폴더에 학습한 모델 파일(`config.json`, `model.safetensors`, `tokenizer.json`, `tokenizer_config.json`)을 넣고 실행합니다.


## 데이터

- **가상 데이터입니다.** 병원명, 주소, 전화번호, 가격은 모두 임의로 만든 값이며 실존 병원과 관계없습니다.
- 시술 정보는 일반적인 안내 수준으로 작성했으며 의료진 검수를 거치지 않았습니다. 실제 진료 근거로 사용할 수 없습니다.
- 의도 분류 문장은 직접 작성한 문장, LLM(Claude, ChatGPT)으로 생성 후 검수한 문장, 공개 의료 Q&A의 **표현 패턴**(성형 은어, 구어체 맞춤법, 시점부터 말하는 구조)을 참고해 새로 작성한 문장으로 구성했습니다. 실제 환자 문장을 그대로 가져오지 않았습니다.
